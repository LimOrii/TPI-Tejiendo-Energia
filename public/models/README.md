# Modelos 3D

Carpeta destinada a los archivos STL generados desde la herramienta (boton
"Descargar STL" en cada turbina) o aportados manualmente por la comunidad
desde Blender, Fusion 360, FreeCAD u otro CAD.

Sugerencia de nomenclatura: `tipo-turbina_diametro_altura_version.stl`
Ejemplo: `hrotor_1.5m_2.5m_v1.stl`
